# 📚 Librería Raíz — Manual de Onboarding y Guía de Desarrollo

¡Bienvenido al equipo de desarrollo del proyecto **Librería Raíz**! Este documento contiene toda la información necesaria para que cualquier nuevo integrante o practicante (como Andrés) pueda incorporarse al proyecto, configurar su entorno de trabajo y contribuir al código de forma completamente autónoma.

---

## 🎯 1. Propósito del Proyecto
**Librería Raíz** es una plataforma web desarrollada para la catalogación, exploración y gestión interactiva de libros y recursos de lectura. El objetivo de este sprint es construir una interfaz web modular, accesible y responsiva, utilizando HTML5, CSS3 y JavaScript vanilla, con despliegue continuo mediante **GitHub Pages**.
